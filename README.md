# html-deck-studio

An agent skill (Claude Code / Agent Skills format) that turns a source document
into an animated HTML slide deck presented PowerPoint-style: the title shows on
entry and every Next click reveals one key-text frame. Background and
illustration images are generated by the Codex CLI with no text in them; all
text and motion are HTML/CSS/JS.

The workflow runs: contract → design direction and 3-slide demo (user approval)
→ plan → image generation → build → verification → optional Vercel deploy.
Agents start from [`SKILL.md`](SKILL.md).

## Install

Copy or clone the folder into a skills directory:

```bash
git clone https://github.com/abm-dungtq/html-deck-studio ~/.claude/skills/html-deck-studio
```

Use `~/.claude/skills/` for every project, or `<project>/.claude/skills/` for
one project.

## Requirements

- Codex CLI, signed in (image generation)
- macOS `sips` or ImageMagick (PNG → JPG)
- Python 3 (local server), Google Chrome (PDF check)
- A browser tool in the agent runtime for the in-page audit
- Vercel CLI, only for deploying

## Deck controls

→ / Space / click: next frame · ← / right-click: back · ↓ ↑ whole slides ·
`O` overview · `F` fullscreen · `A` autoplay · `R` replay · `?` help ·
`#n` in the URL opens slide n · Ctrl+P prints one slide per page.
